---

## 🛠️ The Problem It Solves

Modern web browsers (like Chrome, Edge, Brave, and Opera) use aggressive resource management to save RAM and CPU. When you leave YouTube or YouTube Music running in a background tab while you code, write, or design:
1. **Tab Sleeping / Throttling:** The browser severely limits the tab's Javascript performance, leading to audio stuttering, buffering loops, or track freezes.
2. **Inactivity Prompts:** YouTube's automated system triggers hidden "Still watching?" checks that silently pause your stream.
3. **The Skipping Loop Bug:** In severe background-throttling scenarios, the player can glitch out and rapidly skip forward through your playlist, completely breaking your momentum.

**Our Solution:** This extension runs invisibly in the background with zero configuration. It forces continuous audio processing priority, overrides tab sleep parameters specifically for the player, and automatically clears hidden inactivity roadblocks so your music *never* breaks.

## 🚀 How to Install

Because this is a standard, optimized Chromium extension, you can install it directly from the Chrome Web Store on any of your favorite browsers:

1. Head over to the **[Chrome Web Store Listing](https://google.com)** using Chrome, Edge, Brave, or Opera.
2. Click **Add to Chrome** (or **Get** / **Add to Extension Browser** depending on your application).
3. Confirm the permission prompt to complete the install.
4. Pin the extension to your browser toolbar.
5. Click the icon, ensure it displays **"ON"** in green, and enjoy uninterrupted music!
