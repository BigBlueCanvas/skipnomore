FAQ

Questions? Answers.

YouTube Music keeps skipping songs. Will this fix it?

That’s exactly what it’s for. When YouTube Music plays in a background tab, the browser can throttle or unload the tab and the playlist starts jumping to the next track again and again. The extension keeps the tab awake so the current song plays to the end.

Why does YouTube pause in a background tab and ask “Video paused. Continue watching?”

YouTube shows that prompt when it thinks nobody is listening, and browsers slow down tabs you’re not looking at. Skip Solution answers the prompt automatically and stops the throttling, so YouTube Music stops stopping.

Does it work with YouTube Music?

Yes. It works on both YouTube and YouTube Music: it keeps playback going in background tabs, answers the “Continue watching?” prompt for you, and stops the automatic track-skipping and tab-unloading bugs.

Does it collect my data?

No. No personal data, browsing history or analytics are collected. Page URLs are checked locally, on your device, only to detect youtube.com. Payments are handled by ExtensionPay and Stripe.

Permissions used: storage, scripting, youtube.com and extensionpay.com. Read the full privacy policy.

What happens after the trial?

Install free. Your 7-day trial starts automatically—no email or card. After that, unlock lifetime access for $1.99 once. No automatic charge. No subscription. Payment runs through ExtensionPay with Stripe.

Does it work on Microsoft Edge, Brave or Opera?

Yes. They are Chromium browsers and install the Chrome version from the Chrome Web Store:

  • Edge: open the Chrome Web Store page, click “Allow extensions from other stores” when Edge asks, then “Get” / “Add to Chrome”.
  • Brave: open the Chrome Web Store page and click “Add to Brave” / “Add to Chrome”.
  • Opera: first install Opera’s official Install Chrome Extensions add-on, then open the Chrome Web Store page and click “Add to Opera”.
Does it work on Firefox for Android?

Yes, on Firefox for Android 142 or newer. Install it from Firefox Add-ons, the same as on desktop.

Does it use much battery or CPU?

No. It’s lightweight and only runs on YouTube tabs.
