YouTube Music Stops Playing in a Background Tab: Causes and Fixes

Updated 7 November 2026 · Chrome, Edge and Firefox on desktop

Music plays fine while the tab is in front. Then you move to another tab or app, and after a while YouTube Music stops playing in the background tab, or the page reloads when you go back to it. One possible cause is a browser feature that saves memory. Streaming limits and connection problems are other things to check.

Why background tabs stop

Desktop browsers try to free memory and battery by putting tabs you are not using to sleep:

  • Chrome Memory Saver makes tabs you aren’t using inactive after a period of time; the tab reloads when you return to it. Chrome Help lists active audio or video playback among the activities that may prevent this. Chrome Help
  • Microsoft Edge sleeping tabs pause background tabs to release resources. Microsoft lists “The page is currently playing audio” among the activities that prevent a site from going to sleep. Microsoft Support
  • Firefox unloads tabs automatically only when the system’s memory is low, and avoids tabs that are playing media. Mozilla Support

Notice the pattern: the exemptions apply while audio is actually playing. If playback stops for any reason (a network hiccup, or the “Video paused. Continue watching?” prompt described in YouTube Help), the tab looks idle, and the browser is free to put it to sleep.

A second, unrelated cause is the streaming limit. YouTube Help says that Premium and Music Premium members can stream on one device at a time, that playback “may be paused or not advance to the next video or track” if you exceed it, and that different browsers on the same device count as separate streams. YouTube Help

How to fix it

Chrome: keep the site active

  1. Open Chrome, select More (the three dots), then Settings.
  2. On the left, select Performance.
  3. Next to “Always keep these sites active”, select Add.
  4. Choose Add sites manually, enter music.youtube.com (or youtube.com to cover both sites), and select Add.

Chrome Help also lists pinned tabs among the things that may prevent a tab from being deactivated. Source: Chrome Help: Personalize Chrome performance

Microsoft Edge: never put the site to sleep

  1. Open Settings and more > Settings > System and performance.
  2. Under sleeping tabs, find “Never put these sites to sleep” and select Add. Some Edge versions call this list “Always keep these sites active”.
  3. Enter https://music.youtube.com and select Add.

Source: Microsoft Support: Learn about performance features in Microsoft Edge

Firefox: check what is being unloaded

  1. Type about:unloads in the address bar to see the unloading order and memory use of your tabs.
  2. If YouTube Music is being unloaded because memory is low, closing other heavy tabs is the safe fix.
  3. Mozilla documents an advanced option, setting browser.tabs.unloadOnLowMemory to false in about:config, and warns that changing these settings can affect stability. Only use it if you are comfortable with advanced settings.

Source: Mozilla Support: Unload inactive tabs to save system memory in Firefox

Everywhere: one stream, current browser

  1. Pause YouTube Music on other phones, computers and browsers. YouTube Music Help: “You can only listen to music on one device at a time.” YouTube Music Help
  2. Update your browser. YouTube Music Help says it is available on Chrome, Firefox, Safari and Edge, and recommends the latest browser version. YouTube Music Help Update guides: Chrome, Edge, Firefox.

FAQ

Does pinning the YouTube Music tab help in Chrome?

It can. Chrome Help lists pinned tabs among the settings and activities that may prevent a tab from being deactivated. Adding the site to “Always keep these sites active” is the more direct option.

Does Firefox put YouTube Music to sleep?

Mozilla says Firefox unloads tabs automatically only when the system’s memory is low, and that it avoids tabs that are playing media. You can check the order on the about:unloads page.

Why does the music stop when I start YouTube on another device?

YouTube Help says Premium and Music Premium members can stream on one device at a time, and different browsers on the same device count as separate streams. Above the limit, playback may be paused or may not advance to the next track.
